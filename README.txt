OFADA HEAVEN WEBSITE

OPEN:
Double-click index.html.

REACT 3D DEMO:
The separate /react-app folder contains a Vite + React + TypeScript + Tailwind demo with shadcn-style components. Install Node.js 20.19+ or 22.12+, then run `npm install` and `npm run dev` from /react-app. See /react-app/README.md for details. This demo does not replace the static website above.

EASY EDITING:
1. Images are in /images.
2. Menu items and prices are in /js/script.js in the MENU array.
3. The expanded menu includes Ofada, rice, noodles, mains, sides, drinks and desserts; newly added prices are starter estimates to review and update before publishing.
4. Main business text is directly in the HTML files.
5. Styling is in /css/style.css.
6. The cart is stored in this browser. Checkout collects customer details, requires a delivery address for delivery orders, shows an itemized total, and opens a prefilled WhatsApp or email order draft.
7. Update guest reviews in index.html as customer feedback is collected.
8. Confirm social profile URLs in index.html, menu.html, about.html and contact.html before launch.
9. Reservation email is set on the reservation form in /index.html; email requests open a prefilled mail draft.
10. Google Maps embeds are in the contact sections of /index.html and /contact.html.
11. Public pages include page descriptions, OpenGraph tags, Google Fonts and the local images/favicon.svg asset.

IMPORTANT:
Confirm the restaurant's current menu, prices, opening hours, phone/WhatsApp, reservation process and delivery process before publishing updates.
Set each public page's og:image to an absolute HTTPS URL on the deployed domain before launch so social platforms can reliably fetch the share image.

ADMIN:
The /admin folder contains dashboard pages. Configure authentication and database services before enabling administration.
